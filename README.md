# Sponsorship-Prospectus

The public sponsorship prospectuses, at resources.mismo.org/Sponsorship-Prospectus/:

- `index.html`: 2027 Summit Series and Winter 2027 Summit
- `spring-2027/index.html`: Spring 2027 Summit
- `fall-2027/index.html`: Fall 2027 Summit

Applications go to the Sponsorship Intake flow and land in the Sponsorship Portal (the
`sponsorship` repo). Availability comes from the Sponsorship Availability flow.

**Practice copy:** add `?practice` to any prospectus address to try it on made-up data. Nothing
is sent to the flows; the application shows up in the practice portal
(resources.mismo.org/sponsorship/?practice).

**Before publishing a change:** run the checks in the `sponsorship` repo
(`tests/checks.js`, pointed at this folder). GitHub also runs them after every change here;
a red X on the commit means one failed. See that repo's README.
